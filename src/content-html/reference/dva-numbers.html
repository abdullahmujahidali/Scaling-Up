The three most confused pairs 1. Reserved vs Provisioned concurrency — Reserved = sets a cap. Provisioned = keeps environments warm (the cold-start cure). "Cold start" = Provisioned.

2. Secrets Manager vs Parameter Store — "automatically rotate" = Secrets Manager. "MOST cost-effective" + config = Parameter Store.

3. Blue/Green vs Canary — Blue/Green switches 100% at once. Canary shifts gradually (10% → 100%). Any percentage or "small portion of users" = Canary.
