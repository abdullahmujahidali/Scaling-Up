Developer tools (one family)

These are all "write and ship code" tools. You've already met CodeBuild and CodePipeline; here's the rest of the family:

  • AWS CodeCommit = a private Git repository inside AWS (like GitHub, but AWS's own). Note: AWS has closed it to new customers, but it is still named in the exam guide.
  • AWS CodeDeploy = the tool that pushes finished code onto your servers (it automates deployment).
  • AWS CodeArtifact = a store for packages and libraries (hosting your pip or npm packages). For a Django developer: your own private PyPI.
  • AWS CodeStar = an older "everything in one place" dashboard that tied these services together.
  • AWS Cloud9 = a code editor (IDE) that runs inside your browser.
  • AWS CloudShell = a terminal in your browser with the AWS CLI already installed.

One distinction that could genuinely be asked WAF vs Network Firewall vs Shield. WAF protects a web application (SQL injection and similar). Network Firewall protects the whole VPC network. Shield handles DDoS. All three are security, at three different levels.
