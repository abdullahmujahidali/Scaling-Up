Pricing models: one server, five prices

The exact same EC2 instance can cost five different amounts. The difference isn't the machine — it's the promise you make. The exam never asks the price; it asks which option fits the situation.

~10 min One concept: commitment buys discount Win: the Spot vs Reserved decision
First, recall from C2: cheapest plan with 24×7 support? Which plan does "designated TAM" point to? Does Budgets look forward or back?
Business (24×7, cheapest). Enterprise (designated TAM + 15 minutes). Budgets = forward — it alerts when you cross a limit; Cost Explorer looks back. Today: the thing that actually decides the size of the bill.

If you remember one thing The bigger the promise, the bigger the discount. And Spot is a different kind of deal — not a promise, a risk.

On-Demand = no promise, full price, stop whenever you like.
Reserved / Savings Plans = a 1- or 3-year promise → up to 72% off.
Spot = AWS's spare capacity → up to 90% off, but AWS can take it back with 2 minutes notice.

The deciding exam question is always: can this work be interrupted? If yes (batch processing, testing) → Spot. If no (a database, a production web server) → never Spot.

The story: booking a hotel room

The same room, five ways to get it. On-Demand: walk up to reception today and pay full price — expensive, but come and go as you please. Reserved: sign a three-year contract for that room every night — far cheaper, but you pay whether you show up or not.

Spot: the hotel says "any room still empty at 9pm is yours at 90% off — but if a full-price guest arrives, you must vacate within 2 minutes." A disaster if you're on holiday. An excellent deal if you only came to rest for two hours and can easily go elsewhere.

Savings Plans says something different: "I promise to spend at least X per hour with this hotel chain for three years" — without fixing which room, or even which city. That's why it's more flexible than Reserved.

The details the exam asks for
  • ⭐ Reserved Instance terms: 1 year or 3 years only. There is no 2-year or 5-year term — an option saying "2-year Reserved Instance" is a fake.
  • Three payment options: All Upfront (pay everything now — biggest discount), Partial Upfront, No Upfront (smallest discount). More paid upfront = more saved.
  • Standard vs Convertible RI: Standard = bigger discount, cannot change instance type (only modify). Convertible = smaller discount, but can be exchanged for a different instance type. "Might need to change instance type" = Convertible.
  • Regional vs Zonal RI: Regional = applies across the Region, gives AZ flexibility but does not reserve capacity. Zonal = tied to one AZ and does reserve capacity. "Guarantee capacity in a specific AZ" = Zonal.
  • ⭐ Spot interruption notice: 2 minutes. This number gets asked.
  • ⭐ The data transfer rule — asked often: data IN to AWS is always free. Data OUT costs money. Within one AZ over private IP = free. Across AZs in a Region = charged. Region to Region = more. Out to the internet = most. The phrase to hold: in is free, out is expensive.
  • S3 storage tiers by cost: Standard (frequent access), Standard-IA / One Zone-IA (infrequent — cheaper to store, but a retrieval fee), Glacier Instant / Flexible / Deep Archive (archival — cheapest storage, but retrieval costs time and money). ⭐ S3 Intelligent-Tiering = when access patterns are unknown or changing — AWS moves objects between tiers automatically. That phrase in a question means Intelligent-Tiering, always.
The most common trap — "cheapest" doesn't always mean Spot Questions often ask for the MOST COST-EFFECTIVE option, and Spot looks cheapest — so people pick it. But first check whether the work can be interrupted.

If the question says "production database", "must run continuously", or "cannot be interrupted" — Spot is immediately wrong, however cheap. The cheapest viable answer is then Reserved or Savings Plans.

Remember: the exam isn't asking for the cheapest option — it's asking for the cheapest option that also works. Eliminate the impossible first, then look at price.
Exam English — words that decide pricing questions "fault-tolerant" = able to survive failure and restart. ⭐ On sight, think Spot.
"steady state" / "predictable" = runs the same continuously. → Reserved or Savings Plans.
"spiky" / "unpredictable" / "short-term" = varies, unknown. → On-Demand.
"interrupted" = stopped part-way through.
"upfront" = paid at the start.
"commitment" = a binding promise.
"cost-effective" = best value — not simply cheapest, but "works, at the lowest cost".
"tenancy" = who else shares the hardware (shared or dedicated).
"retrieval" = getting data back out of an archive (appears in Glacier questions).

Bridge to your work You already understand this trade, even if not in AWS's words. On-Demand = a monthly subscription you can cancel any time. Reserved = the annual plan that's cheaper but locks your money in. Every SaaS tool sells this way — your company made the same call on Sentry or GitHub.

Spot maps even more cleanly: it's a Celery task written with retry. If your task is idempotent and can die and re-run safely, running it on a cheap, unreliable machine is fine. If dying mid-way would corrupt data, you'd never put it there. The exam is asking exactly that: is this work idempotent and restartable?
From memory: Spot's discount and its notice period? What Reserved terms exist? Is data IN free or OUT free? And "unknown access pattern" = which S3 class?
Spot = up to 90% off, 2-minute notice. Reserved = 1 or 3 years only (a "2-year" option is a fake). Data IN is free, data OUT is charged. Unknown/changing pattern = S3 Intelligent-Tiering. All four? Then the pricing half of Domain 4 is yours.
