If you remember one thing All four are recognition questions, not depth questions. In each one the exam hands you a single word and that word decides the answer: "HTTP" = ALB, "order" = FIFO, "alarm" = CloudWatch, "closest Region" = latency routing. Catch the word, you have the mark.

1. The load balancer types (ALB / NLB / GWLB)

You met "load balancer" in C6, but the exam usually asks which load balancer. AWS has three, and they differ on one thing only: the level they work at.

Everyday analogy Think of a receptionist in a building. ALB is the receptionist who listens to what you say — "I need accounts" — and sends you to the right floor. It understands your request. NLB is the guard who just opens the door — extremely fast, but doesn't care what you want, only that you get in. GWLB is the security checkpoint everyone must pass through, wherever they're headed.
TypeWorks onExam trigger words
ALB — Application Load BalancerHTTP / HTTPS (layer 7)"HTTP", "web application", "route by URL / path", "microservices", "containers"
NLB — Network Load BalancerTCP / UDP (layer 4)"extreme performance", "millions of requests", "low latency", "static IP", "TCP/UDP", "gaming"
GWLB — Gateway Load BalancerLayer 3 (IP packets)"firewall", "intrusion detection", "inspect traffic", "third-party appliances"

The English of the exam If the question contains "HTTP" or "URL", the answer is ALB. If it says "extreme performance" or "static IP", it's NLB. "Firewall appliance" means GWLB — the rarest of the three, so don't spend study time on it.

2. The three parts of CloudWatch

CloudWatch appeared by name in your lessons, but its three parts were never separated — and separating them is exactly what the exam asks. This is a near-guaranteed Domain 3 question.

PartWhat it isTrigger words
MetricsNumbers over time — CPU, network, disk"monitor performance", "CPU utilization", "graph"
AlarmsDo something when a metric crosses a threshold (notify, auto scale, stop an instance)"notify when", "threshold", "trigger an action", "billing alarm"
LogsThe text your application writes"application logs", "log files", "error messages"
From your work In Django terms: metrics = the server's CPU graph, logs = your logger.error() lines, alarm = the email that wakes you at night when CPU hits 90%. Three different things — and CloudWatch keeps them separate too.

The exam's favourite trap CloudWatch vs CloudTrail. CloudWatch = performance (what is running). CloudTrail = who did what (audit, API calls). If the question says "who deleted" or "audit", the answer is CloudTrail, not CloudWatch. These two appear together on nearly every exam.

3. SQS: decoupling and FIFO

"Decouple" is the exam's single favourite architecture word, and it did not appear once in your lessons. The meaning is simple.

Everyday analogy Picture a restaurant. The waiter writes the order, clips it to the kitchen window, and walks away. They don't stand there waiting for the food. If the kitchen slows down, the waiter keeps taking orders — the tickets just pile up. That is a queue, and that is decoupling: neither side waits on the other. If the kitchen stops entirely, the orders aren't lost — they're safe in the queue.

In AWS that window is Amazon SQS. The exam phrases the benefit like this: "so that one component failing doesn't stop the other" — the answer is SQS.

Queue typeGuaranteeTrigger words
Standard (default)Very high throughput; order not guaranteed, a message can arrive twice"maximum throughput", "order doesn't matter"
FIFOExact order preserved, each message delivered exactly once; lower throughput"order", "sequence", "exactly once", "no duplicates", "banking transactions"

The English of the exam FIFO = First In, First Out. The moment you see the word "order" or "sequence", choose FIFO. That one word settles the whole question.

SQS vs SNS SQS = a queue, one message to one receiver (the kitchen ticket). SNS = notifications, one message to many subscribers (an announcement). "Fan out" or "notify many" = SNS. "Buffer" or "decouple" = SQS.

4. Route 53 routing policies

Route 53 is DNS — it turns a name into an IP address. But the exam asks which IP it should return. Two policies come up most:

PolicyWhat it doesTrigger words
LatencySends the user to the Region that answers fastest for them"lowest latency", "closest Region", "best performance for global users"
FailoverSends everyone to the backup when the primary fails a health check"disaster recovery", "if the primary fails", "active-passive"
WeightedSplits traffic by percentage"10% of traffic", "test a new version"
Simple / GeolocationOne record / route by the user's country"users in Germany must reach"

A fine distinction Latency routing vs CloudFront. Both mean "faster", but CloudFront caches content at the edge, while latency routing sends the user to the nearest full application Region. "Cache" or "static content" in the question = CloudFront. A mention of "Regions" = latency routing.
