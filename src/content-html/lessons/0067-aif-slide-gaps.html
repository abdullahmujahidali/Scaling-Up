1. Metrics for models that predict a number (regression)

Worked example A model predicts two house prices. Real: 100 and 200. Model: 110 and 180. Misses: 10 and 20. MAE = (10+20)/2 = 15 (in money). MAPE = (10% + 10%)/2 = 10% (in percent). RMSE = √((100+400)/2) ≈ 15.8, which is more than MAE because squaring punishes the big miss (20) more. R² = a score from 0 to 1: how much of the ups and downs in prices the model explains. Close to 1 = good.
MetricWhat it tells youTrigger words
MAE (mean absolute error)Average miss, in the real units (money, items)"on average, how many dollars off"
MAPE (mean absolute percentage error)Average miss as a percent, fair for small and big values"percentage", "small and big stores alike"
RMSE (root mean squared error)Like MAE, but big misses count much more"one big mistake is very costly"
R² (R squared)0 to 1: how much of the variation the model explains"0 to 1", "how much is explained"

2. The confusion matrix: where precision and recall come from

Model said YES (spam)Model said NO
Really YESTP: true positive (caught)FN: false negative (missed)
Really NOFP: false positive (false alarm)TN: true negative
MetricFormulaUse it when
PrecisionTP / (TP + FP)False alarms are costly (good email lands in spam)
RecallTP / (TP + FN)Missing a real case is costly (cancer, fraud)
F1Balance of precision and recallYou need both, especially with unbalanced data
Accuracy(TP + TN) / allClasses are balanced and both mistakes cost the same

Trick: Precision has FP in it (the alarms the model raised). Recall has FN in it (the real cases it missed). Example: TP 40, FP 10, FN 20 → precision 40/50 = 80%, recall 40/60 = 67%.

3. Ways a model learns: two new ones

TypeLabels?Example
SupervisedAll data labelledPredict churn from a labelled table
UnsupervisedNo labelsK-means finds customer groups
Semi-supervisedA few human labels + lots without500 labelled X-rays + 200,000 unlabelled. The model labels the rest itself (pseudo-labelling), then retrains.
Self-supervisedNo human labels; the data makes its ownHide a word and predict it (a pretext task). This is how BERT and GPT are pre-trained.
ReinforcementRewards, not labelsA robot learns by trial and reward

Trick: Semi = a few human labels + lots unlabelled. Self = no humans at all; the model guesses the hidden part.

8. The remaining responsible-AI words

TermMeaningExample
Sampling biasThe data does not represent everyone90% young faces → weak on older faces. Fix: balance or augment the data (Data Wrangler).
Measurement biasThe tool that collected the data is wrongA broken scale adds 2 kg to every record
Observer biasThe person collecting or labelling adds their own biasA tagger favours their own university
Confirmation biasA person trusts results that match what they already believeA manager ignores results they dislike
Algorithmic vs human biasBiased data → biased model · the builders add bias
Partial dependence plot (PDP)Shows how one feature changes the prediction while the others stay the same (Clarify). Helps explain black-box models."If income goes up, how does the score change?"
Plagiarism and cheatingA GenAI challenge: essays written by AI, hard to trace an output's source, detection tools growing
Complexity and opacityHard to audit how the system decides
DynamismThe system changes over time
Emergent capabilitiesSurprise skills nobody plannedA travel bot that can also write code

Trick: Sampling = WHO is in the data. Measurement = the TOOL. Observer = the LABELLER. Confirmation = the READER. And the prompt attacks: Poisoning = training data · Injection = hidden orders in the input · Exposure = leaks people's data · Leaking = leaks the prompt · Jailbreak = breaks the safety rules.
