32%

Domain 1 · Development with AWS Services

The biggest domain (~16 questions). All Lambda limits and concurrency, DynamoDB keys/indexes/Query vs Scan, API Gateway, and the SQS/SNS/EventBridge/Kinesis differences. Spend the most time here.

26%

Domain 2 · Security

~13 questions. IAM policy evaluation (explicit deny always wins), STS and roles, Cognito User Pool vs Identity Pool, KMS envelope encryption, and Secrets Manager vs Parameter Store. The easiest points on the exam.

24%

Domain 3 · Deployment

~12 questions. The four deployment strategies (all-at-once, rolling, blue/green, canary), CloudFormation and SAM, buildspec.yml vs appspec.yml, Beanstalk and Fargate.

18%

Domain 4 · Troubleshooting & Optimization

~9 questions. The smallest. CloudWatch (logs/metrics/alarms/Insights), X-Ray tracing, caching options, Lambda memory tuning, and error codes (502 vs 504).

✅ Exam-day checklist

  • Read the last line first — find the qualifying word (MOST cost-effective? LEAST operational overhead?).
  • Cut the two clearly wrong options — your odds go from 25% to 50%.
  • No question gets more than 2 minutes — flag it, move on, come back at the end.
  • Never leave a question blank — there's no penalty for a wrong answer. Always guess.
  • "Serverless / managed" is usually right when the question says "least operational overhead".
  • Any option storing an access key is almost always wrong — an IAM role is right.
  • Read every option to the end — AWS plants 90%-correct options with one wrong word ("ECS with EC2 launch type").
  • If a question seems bizarre — it may be one of the 15 unscored ones. Guess, move on, don't let it rattle you.
